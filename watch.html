Search setup

Search needs a free YouTube API key from Google. It is saved in this browser only and allows about 100 searches a day.

  1. Open YouTube Data API v3 in Google Cloud, create a project if asked, and tap Enable.
  2. Go to Credentials, then Create credentials, then API key.
  3. Copy the key, paste it below and tap Save.
