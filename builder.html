        Other commands
        
    
          
  • grab check tests this device: is ffmpeg working, and what is limited without it.
    • 
          
  • grab on its own asks you step by step.
    • 
          
  • grab update updates the download engine. Try it first when a site stops working.
    • 
          
  • grab help lists every word and option.
    • 
          
  • grab version shows the installed versions.
    • 
          
  • Add --show to any command to print the yt-dlp command without running it.
    • 
        

      


      

        First time? Install grab
        
    
          
  1. Android (Termux): pkg install python ffmpeg git
    2. 
          
  2. Any device with pip: pip install git+https://github.com/pzhub-67/yt-dlp
    3. 
          
  3. Termux only, to reach your Downloads folder: termux-setup-storage, then save to ~/storage/downloads
    4. 
          
  4. iPhone (a-Shell), which has no git: pip install https://github.com/pzhub-67/yt-dlp/archive/refs/heads/main.zip
    5. 
          
  5. Test ffmpeg with python -m grab check. With ffmpeg you get full quality, mp3 and clips. Without it you get the best ready-made file (often 360-720p, audio as m4a) and no clips.
    6. 
          
  6. If the grab command isn't found, use the Python prompt tab, or run python -m grab in its place.
    7.
